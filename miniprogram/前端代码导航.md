## 五、接口封装（api/）

### 5.1 api/index.js —— 所有后端接口

| 函数 | 对应接口 | 用途 |
|---|---|---|
| `loginByPhone(phone)` | `POST /api/auth/wechat` | 家长手机号登录 |
| `isLoggedIn()` / `logout()` | — | 登录态判断 / 退出 |
| `getMembers()` | `GET /api/members` | 家庭成员列表 |
| `createMember(data)` | `POST /api/members` | 添加成员 |
| `saveQuestionnaire(id, answers)` | `POST /api/members/{id}/questionnaire` | 存问卷 |
| `getQuestionnaire(id)` | `GET /api/members/{id}/questionnaire` | 读问卷 |
| `createAssessment(mid, file, view)` | `POST /api/assessments` | 建评估+AI分析 |
| `getAssessments(mid)` | `GET /api/members/{id}/assessments` | 评估历史 |
| `getAssessment(id)` | `GET /api/assessments/{id}` | 评估详情 |
| `getTasks(mid)` | `GET /api/members/{id}/tasks` | 护牙任务 |
| `getVideos(category)` | `GET /api/videos` | 科普视频 |
| `getProducts(category)` | `GET /api/products` | 商品 |

### 5.2 api/request.js

- `BASE_URL`：后端地址（本地 `http://127.0.0.1:8000`，上线改这里）
- `request(path, method, data)`：自动带 token（`access_token`），返回 JSON 的 `data`
- `upload(path, filePath, formData)`：`wx.uploadFile` 封装，上传图片

## 六、关键数据流

```
登录（home 输手机号 → loginByPhone → 存 access_token）
  → 加载成员（getMembers → 切换当前成员，存 current_member_id）
  → 添加孩子（my 页 createMember）
  → 填问卷（questionnaire 页 saveQuestionnaire）
  → 拍照筛查（camera 页 createAssessment → 跳 report 页）
  → 看报告（report 页 getAssessment → 风险分级 + 推荐）
```

**当前成员**用 `wx.getStorageSync('current_member_id')` 全局共享，首页和记录页都读它。

## 七、常见需求怎么改

| 想改什么 | 去哪改 |
|---|---|
| 改颜色/字号 | `variable.less` |
| 改后端地址 | `api/request.js` → `BASE_URL` |
| 加新接口 | `api/index.js` 加函数 → 页面里调用 |
| 改问卷题目 | `utils/questionnaire.js` → `QUESTIONS` |
| 改 tab 栏（名字/图标/数量） | `app.json` + `custom-tab-bar/index.js` |
| 加新页面 | `pages/xxx/` 建 4 个文件 + `app.json` 注册 |

| 改成员表单字段 | `pages/my/index.js` 的 `submitMember` + wxml 表单 |

## 八、调试注意事项（踩过的坑）

1. **域名校验**：本地开发必须在开发者工具「详情 → 本地设置」勾选「不校验合法域名」，否则请求 `http://127.0.0.1:8000` 报错。
2. **LESS 编译**：`project.config.json` 必须含 `"useCompilerPlugins": ["less"]`，否则样式全不生效（纯文字）。
3. **BOM 坑**：不要用 PowerShell `Set-Content -Encoding UTF8` 写小程序文件（会加 BOM 导致 LESS 报 `ParseError`）。用编辑器保存。
4. **miniprogram_npm**：TDesign 组件库是构建产物，已入库 git，不要手改；改了依赖后需重新「构建 npm」。
5. **拍照**：模拟器不支持 `<camera>` 拍照，需真机预览测试拍照功能。
