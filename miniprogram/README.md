# 小程序前端

家长端微信小程序（家校医协同口腔健康管理）。

> 详细说明见 [前端代码导航.md](前端代码导航.md) —— 页面结构、接口、设计令牌、常见改法都在那里。

## 技术栈

- 原生微信小程序 + TDesign 组件库 + LESS
- 主色深青绿 `#15816C`（设计令牌在 `variable.less`）

## 页面

| 页面 | 功能 |
|---|---|
| 首页 | 成员切换 + 健康概览 + 入口 |
| 记录 | 评估历史 + 护牙计划 |
| 我的 | 家庭账户 + 成员管理 |
| 图片收集 | 拍照上传 |
| 报告 | 风险分级 + 推荐 |
| 问卷 | 生活习惯 |

## 运行

微信开发者工具打开本目录，勾选「不校验合法域名」，确保后端跑在 `127.0.0.1:8000`。
