# 后端代码导航

> 用途：后期改代码时，**不用逐行读代码**，先查这张表定位到文件/函数即可。
> 后端技术栈：FastAPI + SQLAlchemy 2.x + SQLite（可切 PostgreSQL）。

---

## 一、目录结构总览

```
backend/
├── app/
│   ├── main.py              # 入口：装配路由、启动建表、预加载模型
│   ├── config.py            # 所有配置项（数据库、JWT、AI 阈值、管理员账号）
│   ├── database.py          # 数据库连接 + ORM 基类 + get_db 依赖
│   ├── core/
│   │   ├── security.py      # 密码哈希、JWT、手机号脱敏
│   │   └── deps.py          # 鉴权依赖（登录校验、角色校验）
│   ├── models/              # ORM 数据表定义（10 张表）
│   │   ├── user.py          # User 用户表
│   │   ├── clinic.py        # Clinic 诊所表 + ClinicUser 操作员表
│   │   ├── case.py          # Case/Image/Diagnosis/Report/ReviewLog/AITask
│   │   └── product.py       # Product 商品表
│   ├── schemas/             # 接口入参校验（Pydantic）
│   │   ├── auth.py          # 登录请求
│   │   ├── case.py          # 病例请求
│   │   └── product.py       # 商品请求
│   ├── services/            # 业务逻辑（核心）
│   │   ├── ai_service.py    # AI 推理（加载 OCC/Front 模型）
│   │   ├── auth_service.py  # 登录逻辑
│   │   ├── case_service.py  # 建病例 + 跑分析
│   │   └── storage.py       # 文件保存
│   └── routers/             # 接口路由（URL → 函数）
│       ├── health.py        # /health
│       ├── auth.py          # 登录接口
│       ├── cases.py         # 患者端病例接口
│       ├── clinic.py        # 医生端病例接口
│       ├── products.py      # 好物推荐（患者查看）
│       └── admin.py         # 平台管理端
├── schema.sql               # 建表参考（实际由 ORM create_all 生成）
└── _smoke.py                # 端到端冒烟测试
```

## 二、入口与配置

| 文件 | 关键内容 | 说明 |
|---|---|---|
| `main.py` | `lifespan()` | 启动时建表 + 预加载 AI 模型 |
| `main.py` | `app.mount("/files", ...)` | 标注图等静态文件访问 |
| `main.py` | `app.include_router(...)` | 挂载所有路由 |
| `config.py` | `settings` | 全局配置单例 |

**改配置**都在 `config.py` 的 `Settings` 类里，用环境变量 `DENTAL_*` 或 `.env` 覆盖。

| 配置项 | 作用 |
|---|---|
| `database_url` | 数据库地址（换 PostgreSQL 只改这里） |
| `data_dir` | 图片存储目录 |
| `jwt_secret` | JWT 密钥（上线必须改） |
| `inference_conf` / `inference_imgsz` | AI 置信度阈值 / 推理尺寸 |
| `admin_username` / `admin_password` | 平台管理员账号 |

## 四、安全与鉴权

| 文件 | 函数 | 说明 |
|---|---|---|
| `core/security.py` | `hash_password()` / `verify_password()` | 密码加解密（bcrypt） |
| `core/security.py` | `create_token()` / `decode_token()` | JWT 签发 / 解析 |
| `core/security.py` | `mask_phone()` | 手机号脱敏 `138****1234` |
| `core/deps.py` | `get_token_payload()` | 从请求头解析登录用户 |
| `core/deps.py` | `require_role(*roles)` | 角色校验依赖 |

**角色**：`patient`（患者）、`clinic`（诊所操作员）、`admin`（平台管理员）。
用法：`payload: dict = Depends(require_role("clinic"))`，`payload["sub"]` 是用户 id。

## 八、一次检测的完整调用链（走查）

```
患者 POST /api/cases（cases.py create_case）
  → require_role("patient") 校验登录
  → case_service.create_case_and_analyze()
       → Case(状态=analyzing) 入库
       → storage.save_upload() 存原图
       → ai_service.predict()  AI 检测（按 view 路由 OCC/Front）
       → ai_service.annotate() 生成标注图
       → Diagnosis(ai_result=结果) 入库，状态=pending
  → 返回结构化结果给患者
医生 PUT /api/clinic/cases/{id}/diagnosis（clinic.py）
  → 只能改自己名下（owner_id=本人）
  → Diagnosis.doctor_edited 更新 + ReviewLog 留痕
医生 POST .../finalize → status=finalized
```

## 九、常见需求怎么改（快速定位）

| 想改什么 | 去哪改 |
|---|---|
| 改 AI 置信度阈值 | `config.py` → `inference_conf` |
| 加/换检测模型 | `services/ai_service.py` → `MODELS` 字典 |
| 加分类模型（病灶） | `services/ai_service.py` 加模型 + `predict()` 填充 `classification` |
| 加一个新接口 | 在对应 `routers/*.py` 加函数，`main.py` 已自动挂载 |
| 改数据库字段 | `models/*.py` 对应类，删 `data/app.db` 重启 |
| 换 PostgreSQL | `config.py` → `database_url`，装上 psycopg |
| 改医生权限规则 | `routers/clinic.py` 里的 `owner_id` 过滤 |
| 改手机号脱敏格式 | `core/security.py` → `mask_phone()` |
| 微信登录接真实接口 | `services/auth_service.py` → `wechat_login()` 的 TODO |
