# 后端代码导航

> 用途：后期改代码时，**不用逐行读代码**，先查这张表定位到文件/函数即可。
> 技术栈：FastAPI + SQLAlchemy 2.x + SQLite（可切 PostgreSQL）。
> 产品：家校医协同口腔健康管理小程序后端（v7 架构）。

## 二、入口与配置

| 文件 | 关键内容 | 说明 |
|---|---|---|
| `main.py` | `lifespan()` | 启动时建表 + 预加载 AI 模型 |
| `main.py` | `app.mount("/files", ...)` | 标注图等静态文件访问 |
| `config.py` | `settings` | 全局配置单例 |

**改配置**都在 `config.py` 的 `Settings` 类，用环境变量 `DENTAL_*` 或 `.env` 覆盖。

| 配置项 | 作用 |
|---|---|
| `database_url` | 数据库地址（换 PostgreSQL 只改这里） |
| `data_dir` | 图片存储目录 |
| `jwt_secret` | JWT 密钥（上线必须改） |
| `inference_conf` / `inference_imgsz` | AI 置信度阈值 / 推理尺寸 |
| `admin_username` / `admin_password` | 平台管理员账号 |

## 四、安全与鉴权

| 文件 | 函数 | 说明 |
|---|---|---|
| `core/security.py` | `hash_password()` / `verify_password()` | 密码加解密（bcrypt） |
| `core/security.py` | `create_token()` / `decode_token()` | JWT 签发 / 解析 |
| `core/security.py` | `mask_phone()` | 手机号脱敏 `138****1234` |
| `core/deps.py` | `require_role(*roles)` | 角色校验依赖 |

**角色（四类）**：
- `family`（家长）—— 自己名下成员
- `school`（校医）—— 本校学生
- `doctor`（医生）—— 所有人，只确认诊断
- `admin`（平台管理员）—— 全局

用法：`payload: dict = Depends(require_role("family"))`，`payload["sub"]` 是用户 id，`payload.get("school_id")` 是学校 id（仅 school 角色）。

## 八、一次评估的完整调用链

```
家长 POST /api/assessments（family.py create_assessment）
  → require_role("family") 校验登录
  → assessment_service.create_assessment_and_analyze()
       → Assessment(状态=analyzing) 入库
       → storage.save_upload() 存原图
       → ai_service.analyze()  两段管线：detect()牙位检测 → classify()龋风险分类
       → ai_service.annotate() 生成标注图
       → Result(detections/classification) 入库，status=done
  → 返回结构化结果（风险等级 + 牙位 + 标注图）

医生 POST /api/doctor/assessments/{id}/confirm（doctor.py）
  → require_role("doctor")
  → Result.doctor_confirmed = True（确认诊断）
```

## 九、常见需求怎么改（快速定位）

| 想改什么 | 去哪改 |
|---|---|
| 改 AI 置信度/尺寸 | `config.py` → `inference_conf` / `inference_imgsz` |
| 接分类模型（龋风险） | `services/ai_service.py` → `classify()` 填真实模型 |
| 加更多分析模型（牙周炎/牙结石） | `ai_service.py` 加模型 + `analyze()` 扩展 |
| 加一个新接口 | 对应 `routers/*.py` 加函数 |
| 改数据库字段 | `models/*.py` 对应类，删 `data/app.db` 重启 |
| 换 PostgreSQL | `config.py` → `database_url` |
| 改学校/医生权限规则 | `routers/school.py` / `doctor.py` 的过滤条件 |
| 改手机号脱敏 | `core/security.py` → `mask_phone()` |
| 微信登录接真实 code | `services/auth_service.py` → `family_login()` |
